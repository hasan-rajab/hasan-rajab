## Flagship Case Study — NEXUS Enterprise AI

**Governed bilingual enterprise RAG with retrieval-time authorization, grounded evidence, auditable decisions, and approval-gated actions.**

[NEXUS Enterprise AI →](https://github.com/hasan-rajab/Gulf-Policy-Assistant)

NEXUS explores a core enterprise-AI problem:

> How do you let an LLM use enterprise knowledge and tools without giving it access to information or actions the user is not authorized to use?

### What it demonstrates

- Arabic/English enterprise RAG
- authorization **before retrieval**
- semantic + lexical retrieval with reranking
- grounded generation with citations and abstention
- approval-gated enterprise actions
- idempotent workflows and guarded state transitions
- audit trails with hash-chain verification
- GitHub Actions release gates
- Google Cloud reference architecture with BigQuery Vector Search, Cloud Run, Gemini, and IAP

### Verified regression evidence

On the bundled fictional demo corpus:

- **14/14** backend + security tests passed
- **8/8** strict RAG evaluation cases passed
- retrieval hit@k: **1.000**
- citation-to-source integrity: **1.000**
- grounding decision accuracy: **1.000**
- language match rate: **1.000**

These are deterministic regression results for the fictional evaluation corpus, **not production guarantees**.
